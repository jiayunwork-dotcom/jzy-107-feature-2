# MHD 通道核算服务

法拉第式磁流体（MHD）发电通道的电学性能常驻核算服务。导电流体在磁场中横穿
通道时感应出开路电压，服务核算接上不同负载后的电流与提取功率，并能对一段
负载电阻区间做扫描，给出功率随负载变化的曲线并标出峰值位置。

通道既可以是一整块均匀通道（单段），也可以是沿流向切成多段、段间按任意
串/并（可层层嵌套）接起来的分段通道。纯 HTTP 接口，不带页面，只管通道本身
的感应与负载匹配。

## 物理模型

| 量 | 公式 | 说明 |
| --- | --- | --- |
| 开路电压 `U_oc` | `B · d · v` | 体感应电动势（非霍尔电压） |
| 通道内阻 `R_int` | `d / (σ · A)` | σ 为流体电导率，A 为通道截面积 |
| 回路电流 `I` | `U_oc / (R_int + R_load)` | |
| 提取功率 `P` | `I² · R_load` | 负载上取出的功率 |

最大功率传输发生在 `R_load = R_int`，此时 `P_max = U_oc² / (4 · R_int)`。
电导率为零时内阻无穷大，电流与功率都为零（扫描不会因此除零崩溃）。

## 目录结构（按职责分文件）

```
app.py               应用入口：装配 Flask 应用
mhd/induction.py     感应计算：单段的开路电压与内阻
mhd/load_solver.py   单段单负载求解：回路电流与提取功率
mhd/sweep.py         单段负载区间扫描与功率峰值定位（采样规则两边共用）
mhd/group_tree.py    分段分组树：结构定义、JSON 解析、引用展开与规模限额
mhd/network_model.py 分段通道统一电路网络建模与求解（节点电压法）
mhd/group_solver.py  分段通道单点核算与扫描（网络模型之上薄薄一层）
mhd/profiles.py      通道档存取：单段档/分组档同一名字空间、引用与并发
mhd/validation.py    输入合法性拦截（计算前打回非法参数）
mhd/routes.py        HTTP 层：只做请求收发与调度，不含算法
tests/               自动化测试（物理关系、守恒、档案引用、并发、接口）
```

扫描与单点核算共用同一个求解函数，保证同一负载处两种口径结果逐位一致。
扫描时若等效内阻落在区间内，会把它补进采样点，使曲线峰值恰好落在
`R_load = R_eq`。

## 分段通道与统一网络求解

分段通道用一棵分组树描述：

* 叶子是一段，参数就是单段通道那五项，段间段段不同（B、v、σ、A 各自独立）；
* 中间节点是组，`connection` 为 `"series"`（串联）或 `"parallel"`（并联），
  `members` 既可以是段，也可以是另一个组，层数不固定。

每一段按戴维南支路建模（`E = B·d·v` 串 `r = d/(σ·A)`），求解时转诺顿形式
压到节点导纳矩阵上：串联就是成员首尾相接（中间分配接线节点），并联就是
成员共接两端，组套组对求解器没有任何特殊。

### 求解方法（统一处理整棵树，不写串/并特例公式）

用节点电压法，把所有负载情况归结为两次基准求解：

1. **有源开路解**：保留全部电动势、负载开路，解一次节点电压；
2. **无源单位注入解**：电动势全置零，在整网正、负端注入单位负载电流，再解一次。

由线性网络叠加原理，负载电流为 `I` 时任一支路/节点量 `x = x_oc + x_u·I`；
整网戴维南等效量为 `U_eq = V₊−V₋`（开路解）、`R_eq = V₊−V₋`（单位注入解），
负载点只需一次标量除法。所以扫描几百个点只建一次网、解两次矩阵。

**电导率为零（段断开）** 的支路电导为 0，不参与矩阵连通，天然产生悬空节点；
求解器只用导通支路做并查集分连通块，每块各自接地解一个对称正定矩阵，
孤立节点与悬空子块都不会产生奇异方程。串联链被开路段切开时，用开路约束
`V_p − V_q = E` 沿开路边传播各块电平，使整网全断时等效电动势仍为链上
各段之和；并联挂着的开路段不约束任何人，效果与删掉这段完全一致。

### 为什么选节点法（考虑过的替代方案）

* **串/并递归等效公式**：正是需求排除的写法，且遇到“串里套并再串”只能层层
  约简，开路环流要另起一套方程；本方法把接法降级为“怎么接线”，以后接法更
  复杂（桥接、抽头）只需新增接线方式，求解器不动。
* **改进节点法/稀疏矩阵分解（SPICE 式 MNA）**：通用性更强，但要处理电压源
  支路带来的非对称增广矩阵与零电导奇异；本网络无纯电压源（每段都串内阻，
  开路即删边），接地拉普拉斯矩阵保持对称正定，普通高斯消元即可，无需选主元
  策略，规模上限内（≤1000 段）numpy 稠密矩阵足够，不额外引入外部服务。
* **图上回路电流法**：选独立回路本身就是预处理负担，悬空支路同样麻烦，
  不比节点法省事。
* **符号化简/闭式等效**：只适用于串并结构，桥接后失效，放弃。

线程内固定 BLAS 单线程并让所有遍历顺序确定，保证同一请求重复提交、
逐段结果逐位相同（有自动化测试钉死）。

## 快速开始

### Docker（一条命令）

```bash
docker compose up --build
```

或分两步：

```bash
docker build -t mhd-service .
docker run --rm -p 8000:8000 mhd-service
```

服务监听 `8000` 端口。

### 本地运行与测试

```bash
pip install -r requirements-dev.txt
python app.py        # 启动服务
python -m pytest -v  # 运行测试
```

## 接口

通道参数（JSON 字段）：

| 字段 | 含义 | 单位 | 约束 |
| --- | --- | --- | --- |
| `magnetic_flux_density` | 磁感应强度 B | T | ≥ 0 |
| `electrode_spacing` | 电极间距 d | m | > 0 |
| `flow_velocity` | 流体速度 v | m/s | ≥ 0 |
| `conductivity` | 流体电导率 σ | S/m | ≥ 0 |
| `cross_section_area` | 通道截面积 A | m² | > 0 |

### `POST /evaluate` — 单点核算

请求里用 `channel` 内联通道参数，或用 `profile` 引用已登记的通道档
（二者必须且只能给其一），外加 `load_resistance`（≥ 0，0 即短路）：

```bash
curl -X POST http://localhost:8000/evaluate -H 'Content-Type: application/json' -d '{
  "channel": {
    "magnetic_flux_density": 2.0,
    "electrode_spacing": 1.0,
    "flow_velocity": 100.0,
    "conductivity": 10.0,
    "cross_section_area": 0.5
  },
  "load_resistance": 0.2
}'
```

```json
{
  "open_circuit_voltage": 200.0,
  "internal_resistance": 0.2,
  "load_resistance": 0.2,
  "current": 500.0,
  "power": 50000.0
}
```

电导率为零时 `internal_resistance` 为 `null`（无穷大无法写入 JSON），
`current` 与 `power` 为 `0.0`。

### 分段通道：`group` 结构

`/evaluate` 与 `/sweep` 里把 `channel` 换成 `group`（`channel`/`profile`/
`group` 必须且只能给一个）：

```json
{
  "group": {
    "connection": "series",
    "members": [
      {"segment": { "magnetic_flux_density": 2.0, "electrode_spacing": 0.5,
                    "flow_velocity": 100.0, "conductivity": 10.0,
                    "cross_section_area": 0.5 }},
      {"group": { "connection": "parallel", "members": [
        {"segment": { "...": "第二段参数" }},
        {"ref": "已登记的通道档名字" }
      ]}}
    ]
  },
  "load_resistance": 0.2
}
```

成员三种写法互斥：`segment`（内联段五项参数）、`group`（嵌套组）、
`ref`（直接引用一个通道档，单段档或分组档都行）。

`load_resistance` 额外接受 `null`，表示负载**开路**——此时整体电流为零，
但并联支路之间的环流照常算，逐段电流带正负号（被倒灌为负）。

分段结果在整体五字段之外增加：

* `segments[]`：每段的 `emf`（电动势）、`resistance`（内阻，断段为 `null`）、
  `current`（实际流过的电流，顺电动势发电为正、被倒灌为负）、`voltage`、
  `emitted_power`（该段发出的功率 `E·I`）、`dissipation`（内阻损耗 `I²·r`），
  以及用于定位的 `index`（前序序号）、`path`、`ref`；
* `groups[]`：每个组的 `connection`、`current`（流过该组的电流）、
  `voltage`（组两端电压）和 `path`（根组为空数组）。

`/sweep` 的整体字段与单段扫描同名；曲线点只含负载/电流/功率，峰值点的
逐段、逐组详情放在响应顶层的 `segments`、`groups`。

### `POST /channels` — 登记通道档（单段或分组）

两种档放在**同一个名字空间**：

```bash
# 单段档（老写法，字段与行为不变）
curl -X POST .../channels -d '{"name":"base","channel":{ ... 五项 ... }}'
# 分组档
curl -X POST .../channels -d '{"name":"pack",
  "group":{"connection":"parallel","members":[{"ref":"base"},{"segment":{...}}]}}'
```

档案引用规则：

* 分组档成员可直接写另一个通道档的名字，常用电极组合只维护一份；
* **引用取实时值，不做快照**：被引档重新保存成新参数后，单点核算、负载扫描、
  查看档案三处一律按最新值展开；
* 保存时校验：引用不存在的档 → 400 拒收；引用链成环（含自己引用自己）→
  400 拒收；校验失败不会覆盖已有档案，也不会留下半成品；
* 删除时若该档正被其它分组档引用 → **409 冲突**，响应列出全部引用者名字，
  删除不生效；
* 所有保存、删除在同一把锁内原子提交，并发交错下不会留下指向空名字的
  分组档。

`GET /channels` 原有 `profiles` 字段（全部档案名）不变，另加
`group_profiles`（分组档名字）用于区分；`GET /channels/<name>` 单段档返回
`channel`、分组档返回 `group`（登记时的原始结构原样回显）。

### 规模上限与错误定位

* 段总数（展开引用后）≤ 1000；单个组直接成员 ≤ 1000；嵌套层数 ≤ 10；
* 空组、非法 `connection`、段参数不合法都在计算前以 400 打回，错误信息
  指出位置（如“根组/成员2/成员2 的段：电极间距必须为正”）与具体字段。

### 错误响应

非法输入在计算前被打回，HTTP 400，响应里带原因：

```json
{"error": "磁感应强度不能为负，收到: -2.0"}
```

引用不存在的通道档返回 404；删除被引用的档案返回 409（见上）。

### `/sweep` — 负载扫描参数

单段与分组都用同一组扫描参数：`load_min` ≥ 0，`load_max` > `load_min`，
`points` 为 2 到 100000 的整数。等效内阻落在区间内部时会自动补成采样点，
因此峰值精确落在 `R_load = R_eq`。等效内阻无穷大（整网断开）时区间内
全程电流、功率为零，不报错、不除零。

通道档只保存在进程内，重启即清空。

## 基准算例（手算核对）

B = 2 T、d = 1 m、v = 100 m/s、σ = 10 S/m、A = 0.5 m²：

- 开路电压 `U_oc = 2 × 1 × 100 = 200 V`（百伏量级）
- 内阻 `R_int = 1 / (10 × 0.5) = 0.2 Ω`
- 负载匹配时 `I = 200 / 0.4 = 500 A`，`P_max = 500² × 0.2 = 50 kW`

该算例与下列电学关系一起钉在 `tests/` 的回归测试里：

1. 磁感应强度翻倍 → 开路电压翻倍；流速翻倍 → 开路电压同样翻倍
2. 扫描功率曲线峰值落在 `R_load = R_int`；负载改为 `2·R_int` 时功率下降
3. 电导率为零 → 电流为零、功率为零
4. 单点核算与扫描曲线在同一负载处结果完全一致

分段通道另有一组判据（`tests/test_group_network.py` 等）：单段分组与老写法
逐字段一致；两同段串/并分别与间距加倍/截面积加倍的单段一致；同类型组嵌套
与摊平一致；任意结构任意负载下并联组满足 KCL、`Σ 段发出功率 = 负载功率 +
Σ 内阻损耗`；零电导段在并联中等同删除、在串联链中掐断该链且扫描不除零；
分组扫描峰值精确落在等效内阻；同一请求重复提交逐段结果逐位相同；被引档
删除冲突 409、成环/悬空保存拒收、并发保存删除后不存在悬空引用。
