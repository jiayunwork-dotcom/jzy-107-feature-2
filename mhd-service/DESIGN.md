# 分组通道：网络建模与档案引用设计说明

## 1. 需求回顾

一条真实通道沿流向切成多段，每段的 B、v、σ、A 都可能不同；焊汇流排
时接法任意：前几段串成一组再和单段并联、两个并联块首尾串联、组里套组，
层数不固定。需要：

- 单点核算与负载扫描都吃整棵分组树；
- 输出整体等效电动势/等效内阻/负载电流/功率，逐段给出电动势、内阻、
  实际电流（被倒灌为负）、发出功率、内阻损耗；每个组给出流过它的电流
  和两端电压；
- 负载开路时并联支路间的环流要能看见；
- σ=0 的段视为断开，不能产生悬空节点/病态方程；
- 分组结构能存成通道档、按名引用、引用里再套引用，且删除、成环、悬空
  引用、并发交错都要有明确规矩。

## 2. 算法选型：一般电路网络统一求解（不写串/并特例公式）

明确放弃的做法是「串联 E 相加 r 相加、并联 r 取倒数，然后层层递归」。
它在两个维度上是债务：

1. 段间互灌电流在纯等效公式里被直接抹掉——而这恰恰是这次最想看清的量；
2. 以后出现不是纯串/纯并的接法（桥接、多母线、跨接）就要再写一套公式，
   递归层数与特例数随拓扑种类增长。

实际采用的是**节点电压法（改进节点分析的诺顿形式）+ 叠加定理**，
串/并在建模阶段只是两种接线动作，求解器眼里只有「节点、导纳、注入」。

### 2.1 元件模型

每段是戴维南支路：电动势 `E = B·d·v` 串内阻 `r = d/(σ·A)`。入网时转成
诺顿等效——电导 `g = 1/r` 跨在正/负节点之间，电流源 `g·E` 注入正极：

```
   p ──┬── g ──┬── n
       ↑ gE
```

σ=0 的段 `r=∞、g=0`，直接不生成边（断头），不引入任何大数。

### 2.2 串/并如何落到拓扑（不落到公式）

- 串联组成员首尾顺接：成员 i 的负极端汇流点 = 成员 i+1 的正极端汇流点；
- 并联组成员的正极全部接到同一根正极汇流排、负极全部接到负极汇流排；
- 组与父组之间只由理想导线（汇流排）连接。

导线用并查集合并成「超节点」；导纳支路只存在于超节点之间。这样同电位
节点在矩阵里天然只有一个变量，没有零阻边导致的奇异问题。

### 2.3 三次线性解 + 叠加（扫描整区间只解两到三次矩阵）

线性含源电阻网络在负载上是戴维南结构，一切量都是负载电流的仿射函数：

1. **开路解（oc）**：全部电动势在、负载不接。按导纳边求连通分量，每个
   分量钉一个参考节点解节点电压。它直接给出等效电动势，以及——更关键的
   ——**并联支路间的环流**（开路时组总电流为零，但支路电流不为零，
   方向相反的两支互为倒灌）。断头悬空的分量也照解：断头把网络切成若干
   分量，每个分量内部由自己的电动势维持唯一的电流分布，钉一个本地参考
   即可，不需要任何正则化。
2. **单位负载解（c）**：所有电动势置零，取「1A 负载电流」状态（正极抽出
   1A、负极注入 1A）。两极连通时：两极电位差即**等效内阻**；每条支路、
   每条汇流排上的电流就是该支路对负载电流的**分配系数**。
3. 任意负载 R 下：`I_load = U_oc / (R_eq + R)`，
   `X(R) = X_oc + I_load · X_c`。所以扫描 10 万个采样点也只是在开路解与
   分配系数上做线性组合，矩阵只解两到三次。

短路（R=0）不需要特殊处理：它只是 `R_eq + 0`。

### 2.4 零电导率（断头）与病态处理

- **不用大电阻/大电导**作为常规手段。断头直接无边，按导纳边做连通分量，
  每分量钉本地参考节点，约化拉普拉斯矩阵严格正定；
- **等效内阻按连通性严格判定**：root 两极在同一导纳连通分量才有有限
  R_eq（取 c 解的两极电位差），否则就是 `inf`（JSON 里为 `null`），
  扫描不会把 `inf` 插进采样区间，也不除零；
- 断头分量（含闭合回路的浮动网络，例如两个断头段在内部互相成环）电流、
  组间环流都由各自分量的开路解给出；
- **唯一用到弱电导的地方**：全断开时「整体开路电压」这个纯展示量在物理
  上本无定义（两极间没有任何导纳路径）。为了让单段 σ=0 的分组与老单段
  口径在展示字段上保持一致（老口径 σ=0 仍返回 `B·d·v`），补一次
  自适应弱电导极限解：`g_weak = max(1e-8 · g_max, 1e-12)`，断头以它
  入网，取极限电压。**这个解只用于电压展示，绝不参与任何电流、功率、
  内阻、扫描曲线**。

### 2.5 线性代数：最小度排序 + 稀疏 LDL^T

约化节点导纳矩阵对称、严格对角占优、正定，所以：

- 用近似最小度（minimum-degree，平局取编号最小）排序，串并联网络的树宽
  很小，填元很少；
- 稀疏 LDL^T 数值消元，正定主元恒正，不需要选主元；
- 建网、排序、消元的所有分支只依赖结构与数值比较，同构网络的浮点运算
  次序完全固定 → 同一请求重复提交，逐段结果逐位相同。

100 段满规模：求解 < 10 ms，10 万点扫描约 50 ms（曲线点只组合 I/P，
逐段明细只在峰值点展开一次）。

### 2.6 考虑过但放弃的替代方案

| 方案 | 放弃原因 |
| --- | --- |
| 串/并等效公式递归 | 看不到互灌电流；接法一复杂就要再写特例；与需求的明确要求冲突 |
| MNA + 通用稠密矩阵 + numpy | 百段以下稠密消元纯 Python 太慢；引入 numpy 要改镜像与依赖，而网络树宽小，稀疏 LDL 已足够快，不增加任何外部服务/重依赖 |
| 断头统一用大电导（1/ε）正则化 | 量级悬殊会污染正常支路的有效数字，且把「严格为零的断头电流」算成微小非零；只在展示开路电压这一处用弱电导，污染可忽略（1e-8 相对）且不外溢到电流功率 |
| 断头统一当理想电压源（强制端电压=E） | 强制了不存在的约束，多个断头串联会矛盾，电流不再恒为零，物理上错 |
| 通用电路仿真（改进节点分析含任意电源/受控源） | 对本问题过重；这里只有独立电压源串电阻一种元件，诺顿形式足以覆盖 |
| 符号化/区间算术保证零误差 | 无必要，浮点叠加的能量守恒残差在 1e-9 相对量级，远小于验收容差 |

## 3. 结果口径

- 电流正方向：段电流以**该段电动势方向**为正（从正极流出），被别的段
  倒灌时为负；组电流以**从组正极流出到外电路**为正；负载电流同方向。
- 段功率：`generated = I·E`（被倒灌时为负，表示被充电）、
  `dissipation = I²·r`、`terminal = I·E − I²·r`（对外净输出）。σ=0 段
  三者均为 0。
- 组：`current`、`voltage = V_p − V_n`（带载时等于开路电压减内阻压降）、
  `power = current·voltage`。组的两极不在同一导纳分量且与 root 不连通时，
  电压取弱电导极限展示值；此时该组电流恒为零。
- 守恒关系（测试逐条钉死）：
  - 每个并联组：成员电流代数和 = 组电流；串联组：各成员电流相等；
  - 根组电流 = 负载电流；
  - Σ 各段发出功率 = 负载功率 + Σ 各段内阻损耗。

## 4. 分组档与引用

### 4.1 存储与名字空间

- 单段档与分组档在**同一个名字空间**。老接口行为与字段不变：
  `GET /channels` 的 `profiles` 仍是全部档名；额外给 `groups` 标出分组档。
- 分组档保存的是**未展开的树**：`{"ref": "name"}` 原样保留（查看档案
  返回登记时的结构），计算时再按名字取被引档。
- 引用目标既可以是单段档，也可以是分组档；一个分组里可以多次引用同一档。

### 4.2 引用值口径：动态引用（三处一致）

被引档重新保存后，**单点核算与负载扫描立刻使用新参数**；查看档案看到的
始终是登记时写的引用结构（而不是某时刻的快照值）。即「结构看存档，
数值看当前」。不做保存时快照的理由：汇流排组合只维护一份是这次的核心
诉求，快照会让「改一段、处处生效」失效，并且被引档更新后引用方口径
分裂。单点、扫描、查看三处由同一个 `resolve_tree` 出口保证口径一致。

### 4.3 保存/删除规矩（全部在同一把锁内原子完成）

- **悬空引用**：保存分组档时，所有 `ref` 必须已经存在（自引用除外，它
  随后会被环检测挡住），否则 400 拒收并列出缺失名字；
- **成环**：保存时对「把新内容也放进视图」的引用图做深度优先环检测，
  含自引用与互相引用；成环 400 拒收，旧版本保留不动；
- **删除冲突**：被任何分组档引用着的档不许删除，返回 409 并列出全部
  引用方；解除引用后可删；
- **并发交错**：保存（含悬空检查、环检测、展开）与删除在 `ProfileStore`
  的同一把可重入锁内完成，外部观测不到「删了一半/存了一半」的中间状态。
  「删除 A」与「保存引用 A 的分组」并发时，只可能出现两种结局：
  删除被 409 挡住，或引用保存被悬空检查拒收——不会留下指向空名字的档。
- 内联分组请求里的 `ref` 在核算时同样解析：不存在 → 400，环 → 400。

### 4.4 上限

- 总段数（含引用展开后）≤ 100；嵌套深度 ≤ 16。保存时先查内联部分，
  展开引用后再查一次（跨档叠加也可能超限）。
- 扫描点数沿用单段通道的 2…100000。

## 5. 模块职责

```
mhd/
  induction.py         段物理参数：E = Bdv、r = d/(σA)（未改）
  load_solver.py       单段单点求解（老口径，未改）
  sweep.py             单段扫描与采样补点（老口径，采样函数被分组复用）
  groups.py            分组实体树类型 + 引用展开（resolve_tree）
  group_validation.py  分组树输入校验（位置化错误信息、上限）
  linalg.py            最小度排序 + 稀疏 SPD（LDL^T）线性求解原语
  circuit.py           树 -> 网络拓扑；分量求解；叠加结果；公开 solve_channel
  group_sweep.py       分组扫描（复用同一次解，曲线点只组合 I/P）
  profiles.py          档案仓库：两种档、引用校验、环、删除冲突、并发
  routes.py            HTTP 收发与调度（无算法）
  validation.py        单段输入校验（未改）
```

路由层不出现任何电路计算：它只做「选来源 → 调内核 → 序列化」。
